## Syncing from the parent `RobloxCursor` folder

The **parent** `RobloxCursor/default.project.json` now also pulls in this game:

- `ReplicatedStorage.BendingUI` ← `Bending/src/shared/BendingUI.luau`
- `StarterPlayerScripts.Bending` ← `Bending/src/client`

So if you run `rojo serve` from **`RobloxCursor`** (repo root), the plugin should still sync **Bending** alongside the main `Client` scripts.

You can still use **`rojo serve`** from inside **`Bending`** only if you prefer the smaller project file.
