# MCU

MCU hero battler (Rojo + Luau). Starting roster: **Scarlet Witch**, **Captain Marvel**.

## Connect Rojo

```powershell
aftman install
rojo serve
```

Studio → Rojo plugin → **Connect** → Play.

## Scarlet Witch

**Left panels:** Hex Blast modes (Single / Barrage) and Telekinesis modes (Single / Multiple).  
**Left extras:** Teleportation (V), Fear Inducement (G).  
**Bottom bar:** Q / E / F / T / C / X.

| Key | Ability |
|-----|---------|
| **Q** | Hex Blast — Single bolt or Barrage (slow expand → accelerate to cursor) |
| **E** | Telekinesis — hold to lift, click to throw, release to drop |
| **F** | Hex Flight (Shift boost). Slight camera roll from character bank |
| **T** | Hex Beam (hold) — toward mouse; stops on first hit |
| **C** | Shield (hold) — welded to you; deflects projectiles |
| **X** | Disintegration — blast hovered target, then dissolve |
| **V** | Teleportation (left extras) |
| **G** | Fear Inducement (left extras) — hovered target loses powers 10s |

Captain Marvel abilities are HUD-only for now.
